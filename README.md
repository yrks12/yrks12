### Hi there 👋

I build **local-first AI tools** — things that run on your own machine, fast, and without shipping your data to someone else's cloud.

**What I work on**

- 🎬 **Video pipelines** — automated editing, captions, narrated explainers, short-form clips
- 🗣️ **Speech** — on-device transcription and text-to-speech, including Hebrew
- 🤖 **Agent orchestration** — teams of AI agents that plan, build, review and ship
- 🔎 **Search** — fast offline full-text search for non-Latin languages
- 🛡️ **Security tooling** — network scanning, log analysis, vulnerability checks
